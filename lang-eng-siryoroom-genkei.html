TOEIC L&R Part 5 実戦ロジック資料

正解の肢として出される 「動詞の原形（Base Form）」 完全攻略

三単現の -s や過去形（-ed）の引っかけを無力化する「動詞の原形」が必須となる全9パターンを徹底整理。助動詞の隙間から仮定法現在、使役・知覚・helpの原形不定詞までを完全網羅しました。

01

「動詞の原形」が要求される全9パターンの全体像

英語で動詞の原形（Base Form / 原形不定詞）が正解となる構文は、以下の9系統に集約されます。TOEICでは時制の一致や主語の人称に惑わされず、この支配構造を見抜くことが鉄則です。

Pattern 01

助動詞 ＋ (副詞) ＋ 原形

will, can, mustなどの直後（副詞の割り込み注意）

will carefully review
Pattern 02

to 不定詞（to ＋ 原形）

「前置詞のto（後ろは -ing）」との混同を排除

plans to expand
Pattern 03

命令文の文頭

主語が欠落した指示・依頼構文

Please submit the form.
Pattern 04

使役動詞 ＋ O ＋ 原形

make / have / let ＋ O ＋ 原形不定詞

had the tech install it
Pattern 05

知覚動詞 ＋ O ＋ 原形

notice / see / hear ＋ O ＋ 原形不定詞

noticed him enter
Pattern 06

help の特殊語法

help (O) (to) 原形 / 動詞2連続の許容

helps prevent disruptions
Pattern 07

提案・要求 that 節（仮定法現在）

request / suggest that S (should) 原形

requested that he wear
Pattern 08

助動詞的表現・慣用構文

had better / cannot help but 等の直後

had better confirm it
Pattern 09

Why not 〜 ? 提案構文

リスニングやビジネス対話の定型提案

Why not consult legal?
02

Pattern 06 & 07 深掘り解説：help と 仮定法現在（that節）

全9パターンの中でも、受験生が特につまずきやすく正答率が大きく分かれる「Pattern 06（help）」と「Pattern 07（仮定法現在）」の構文構造を詳しく分解します。

Pattern 06 Focus 準使役動詞 help の二面性

help は「to」が省略されて原形が直接置かれる

現代のTOEIC本試験では、to 不定詞よりも「to が消えた原形不定詞」が圧倒的に好まれます。第3文型で動詞が2つ連続して見える形に惑わされないことが重要です。

① 第5文型（S ＋ help ＋ O ＋ 原形）
The software helps staff locate items.

「ソフトウェアはスタッフが品目を見つけ出すのを手助けする」

② 第3文型（S ＋ help ＋ 原形 ※動詞2連続）
Regular maintenance helps prevent breakdowns.

「定期的な点検は故障を防ぐのに役立つ」（helps の直後に原形 prevent）

Pattern 07 Focus 提案・要求動詞の that 節（仮定法現在）

時制の一致や三単現の -s を完全無視する「should の脱落」

要求・提案・命令を表す動詞に続く that 節内は、本来介在する意志の助動詞 should が省略されるため、主語が三人称単数でも、主節が過去形でも、動詞の原形になります。受動態のときは be ＋ 過去分詞 になる点に注意してください。

The coordinator requested that each participant [should] wear an ID badge.
※ 主節が requested（過去形）かつ each participant（単数）であっても、wears や wore ではなく原形の wear。
Management recommended that the proposal [should] be approved immediately.
※ 受動態の場合、is や was ではなく be動詞の原形 be を選択する。
03

受験生が混同しやすい「notice」と「request」の構造対比

「原形」が使われる場所の違いを峻別します。知覚動詞は SVOC の C に原形が来ますが、that 節内は通常の時制になります。

動詞の種類 SVOC（第5文型）での動作 that 節（第3文型）での動作
notice
（知覚動詞・事実の認知） 		notice ＋ O ＋ 原形不定詞
noticed him enter the room 		notice that ＋ S ＋ 通常の時制（過去形等）
noticed that he entered / was absent
request
（要求動詞・行動の促し） 		request ＋ O ＋ to 不定詞
requested him to enter the room 		request that ＋ S ＋ 動詞の原形（仮定法現在）
requested that he enter the room
04

Part 5 空欄3秒判定ステップ（動詞の原形編）

選択肢に動詞のバリエーション（原形、過去形、三単現、分詞）が並んだ際の走査手順です。

STEP 01
文頭が空欄で主語がないか？
YES 命令文（動詞の原形）
STEP 02
直前に助動詞、または「助動詞＋副詞」があるか？
YES 助動詞の直後（動詞の原形）
STEP 03
make / have / let / notice / see / help ＋ 目的語 の直後か？
YES 原形不定詞（動詞の原形）
STEP 04: HIGH-LEVEL CHECK
主節に request, suggest, essential that があるか？
that 節内は時制無視で「動詞の原形（仮定法現在）」！
